
# 🛒 Grocery App

A modern and responsive grocery shopping application built with **Flutter**.

The app provides a complete grocery shopping UI with multiple screens for browsing products, viewing product details, managing the cart, favorites, and user account.

The application is designed to support both **Portrait** and **Landscape** orientations.

## 📐 Responsive Design

The application is built with responsive design in mind.

It adapts its layout depending on the device orientation:

- **Portrait:** Mobile-friendly vertical layout.
- **Landscape:** Optimized horizontal layout with better use of the available screen width.

This makes the application suitable for different screen sizes and orientations.
